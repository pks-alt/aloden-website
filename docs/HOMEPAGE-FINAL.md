# Aloden Homepage — Final V10 Design Baseline

**Status:** FINAL / LOCKED FOR THE V1 PAGE SYSTEM  
**Working branch:** `feature/homepage-browser-preview`  
**Implementation source:** `preview/index.html` + `preview/style.css` + `preview/app.js`

This document records the approved homepage UX/UI baseline that all remaining Aloden V1 pages should inherit. Changes to the items marked locked below require explicit design approval.

## Locked Visual System

- Four-dot Aloden identity with black + violet as the primary brand language
- Instrument Sans for primary typography
- IBM Plex Mono for small technical/editorial labels
- Predominantly light editorial canvas
- Selective black/dark contrast sections
- Compact section spacing; remove unnecessary empty vertical space
- Strong readable text contrast
- Controlled border radii and restrained shadows
- Avoid making every section a rounded card grid
- Purposeful violet accent rather than excessive multi-color AI gradients

## Accessibility and Responsive Requirements

The production implementation must preserve:

- semantic structure
- keyboard accessibility
- visible focus states
- readable type sizes and contrast
- appropriate touch targets
- reduced-motion support
- responsive recomposition rather than simply shrinking desktop layouts

## Performance Requirements

- lightweight visual effects
- optimized product media
- no unnecessary animation libraries
- strong Core Web Vitals
- fast initial render

## SEO / Discovery Requirements

Production pages must include:

- page-specific metadata
- canonical URLs
- Open Graph metadata
- structured data where appropriate
- sitemap and robots configuration
- crawlable semantic content
- useful internal linking
- content structure suitable for traditional search and AI discovery

## Do Not Change Without Explicit Approval

- Aloden four-dot logo direction
- primary H1 and supporting line
- navigation labels
- homepage section order
- product hierarchy
- core black + violet design language
- Instrument Sans / IBM Plex Mono typography direction
- compact editorial density
- homepage positioning as AI Product Engineering + Digital Modernization

## Next Design Phase

All remaining V1 pages should now be designed from this final homepage system rather than starting from a new visual direction.
