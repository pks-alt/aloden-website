# Aloden Website — Version 1 Scope

## Positioning

Aloden LLC will present itself as an **AI Product Engineering and Digital Modernization** company. Healthcare is an important proof point, but the company website should not position Aloden as healthcare-only.

## Primary Homepage Message

**We build and modernize intelligent digital products.**

## Explicitly Out of Scope for V1

- Industries section
- Careers section
- Full CMS

## UX and Engineering Requirements

### Accessibility

Accessibility is a launch requirement, including:

- strong color contrast
- full keyboard navigation
- clear focus states
- semantic HTML
- descriptive alt text
- sensible motion
- `prefers-reduced-motion` support
- readable typography
- WCAG-conscious component behavior

### Performance

Performance is a launch priority:

- optimized media
- lightweight animation
- efficient rendering
- strong Core Web Vitals
- fast initial page loads

### SEO

The implementation should support:

- crawlable semantic page architecture
- page-specific metadata
- canonical URLs
- Open Graph metadata
- XML sitemap
- robots configuration
- structured data where appropriate
- strong internal linking
- content structure suitable for traditional search and AI discovery

### Content Management

V1 content will be developer-controlled in the codebase. A CMS can be introduced later if editorial needs justify it.

## Design Direction

The experience should feel premium, modern, technically credible, restrained, and intentional. Motion should support comprehension and product storytelling rather than serve as decoration.
