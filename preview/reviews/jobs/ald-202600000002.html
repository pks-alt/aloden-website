Key responsibilities

  • Design and maintain a unified PostgreSQL schema for the product’s user journeys.
  • Implement backend APIs, validation, relationships, and transactional data changes.
  • Write versioned migrations and safe deployment and rollback procedures.
  • Build audit history that makes important data and permission changes traceable.
  • Implement consent records and enforce the appropriate data-access rules.
  • Work with frontend, architecture, and QA colleagues to keep integrations and data contracts reliable.

What you bring

  • Practical backend development and PostgreSQL database-design experience.
  • Understanding of relational modeling, migrations, transactions, and API design.
  • Ability to implement authorization and validate data at trusted server boundaries.
  • Experience investigating data-quality and integration failures.
  • Clear documentation of schemas, interfaces, and operational assumptions.

Helpful experience

  • Experience with consent-aware applications or auditable multi-user workflows.
  • Experience designing test fixtures and migration verification.
  • Examples of database performance or reliability improvements you have delivered.
